# About

Project based on Polish game - Robbo Millennium by LK Avalon that I loved playing in my childhood years.

# Technologies
- C++
- SDL2

# Controls

**Robbo moving and directions for shooting:**
- `W` `S` `A` `D`
- `↑` `↓` `←` `→`

**Shooting:**
- `SPACE` + direction

**Self-destruction:**
- `ESC`

**Quit to menu:**
- `F10`
